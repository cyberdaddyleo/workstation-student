# 大学生工作台使用指南

适用版本：v1.1。项目主页：[workstation-student](https://github.com/cyberdaddyleo/workstation-student)。

大学生工作台把课表、学科资料、成绩、证书、升学就业规划和生活记录放在同一个宿舍界面中。主程序是一个 `index.html` 文件，无需安装应用、注册账号或部署服务器。查看功能截图和完整介绍，请回到 [README](../README.md)。

## 1. 下载并打开

1. 进入项目主页，点击 **Code → Download ZIP**。
2. 解压下载的压缩包，把整个文件夹放在一个固定位置。
3. 找到 `index.html`，用 Chrome 或 Edge 打开。若双击没有打开浏览器，可右键选择打开方式。
4. 第一次进入时，先选择形象，再选择使用方式：**先看看示例同学**，或者 **直接用我自己的**。
5. 自己开始使用时，填写称呼、学历和入学年份；学校、专业可按需要填写。

建议在电脑上使用，屏幕宽度为 1280 像素或以上。普通使用不需要 Node.js；只有使用可选的 AI 本地中转时才需要。

示例同学用于体验功能。准备正式记录时，点击左上角 **开始用我自己的**，填写自己的信息，再点 **清空并开始**。这会清空示例数据，包括体验过程中新增的记录，保留已选形象和 AI 设置；有需要保留的内容请先备份。

请始终用同一个浏览器、同一个浏览器用户配置打开固定位置的文件。聊天软件或网盘的预览窗口可能不支持持久保存，不适合长期录入。若页面提示本地存储不可用，请先导出备份，再改用正常的浏览器窗口。

## 2. 第一次使用，先完成三项设置

| 位置 | 要设置什么 | 影响 |
|---|---|---|
| 设置 → 个人信息 | 称呼、学历、入学年份、学制 | 形象、学期列表和预计毕业年份 |
| 设置 → 学期与作息 | 本学期、开学日期、周数、每节课上下课时间 | 周次计算、课表和上课提醒 |
| 设置 → 成绩规则 | 绩点算法、选修课和通识课是否计入 GPA、毕业总学分 | GPA 和学分进度 |

开学日期应填 **第 1 周的周一**。课表显示的第几周不正确时，优先检查这里。课表节次与学校不一致时，在作息时间中调整，必要时使用 **加一节** 或 **减一节**。

## 3. 建立本学期课表

### 手动添加

1. 进入 **课表**，确认当前显示的学期。
2. 点击空白格子或 **添加课程**。
3. 填写课程名称、学分、课程类型、老师等信息，再设置星期、节次、周次和地点。
4. 一门课每周有多个上课时间时，在同一门课里添加多个时间段。
5. 录入后检查周视图；有单双周课程时，再切换周次检查是否正确。

### 从 Excel 或教务系统批量导入

点击 **导入课表 → 下载模板**，用 Excel 填写后，连同第一行表头一起复制并粘贴到导入框。可识别这些列：

| 课程名称 | 星期 | 开始节 | 结束节 | 周次 | 地点 | 教师 | 学分 | 类型 |
|---|---|---|---|---|---|---|---|---|
| 操作系统 | 1 | 1 | 2 | 1-16 | 博学楼 A204 | 韩老师 | 4 | 必修 |
| 操作系统 | 3 | 3 | 4 | 1-16 | 博学楼 A204 | 韩老师 | 4 | 必修 |

星期使用 `1–7` 或 `周一` 等写法；周次可写 `1-16`，单双周可写 `1-16单`、`1-16双`。确认识别到的课程数和上课时间数，再点击 **导入**。

同一学期的同名课程会合并，上课时间会继续追加。不要反复导入同一份课表，以免重复添加时间段。

如果教务系统只能提供截图，点击导入窗口里的 **复制提示词**，把提示词和课表截图交给自己选择的 AI 整理，再把表格贴回来。导入前核对课程、单双周和节次；把截图交给第三方 AI 时，该服务会收到截图内容。

## 4. 把笔记、文件和复习卡片归到学科

本学期课程会出现在宿舍书架上。点击书本或进入 **学科资料**，选中学科后即可整理资料。自学内容，例如考研数学、雅思或编程，可用 **新学科** 添加。

| 内容 | 使用方式 |
|---|---|
| 笔记 | 新建并编辑，支持 Markdown 标题、列表、表格和加粗；编辑会自动保存，可导出 Word |
| 文件 | 拖入课件、作业或图片；单个文件上限为 50 MiB（界面标为 50MB），图片、PDF、文本支持预览 |
| 链接 | 保存课程网站、题库、网盘或老师主页 |
| 复习卡片 | 录入一问一答，按当天待复习安排回顾；也可以批量导入或用 AI 生成 |

文件保存在当前浏览器的 IndexedDB 中，不会自动同步到其他设备。删除课程后，关联学科资料会保留为自学科目；暂时不用的学科可以收起。

建议每次课后做三件事：上传课件、补充一篇笔记、把容易忘的知识点写成复习卡片。需要学习时，点学科中的 **学这科** 开始专注。

## 5. 录入成绩，查看 GPA

1. 进入 **成绩与 GPA**，选中对应学期。
2. 手动填写课程成绩，或点 **导入成绩**，粘贴带表头的成绩表。
3. 导入至少需要 **课程名称** 和 **成绩** 两列，可加 **学分、类型、学期**。
4. 检查 **默认放进** 的学期。表格中的学期名称能匹配现有学期时会自动归类，否则使用默认学期。
5. 导入后检查课程、学分和成绩，再查看学期趋势、累计 GPA、学分进度或目标 GPA 计算器。

同一学期的同名课程会更新成绩。等级制成绩支持“优秀、良好、中等、及格”等；“通过 / 合格”只计算学分，不计入绩点。**导出** 可下载 CSV 成绩单。

GPA 用于个人参考，请在 **设置 → 成绩规则** 中选取与学校一致的算法。重修、等级折算等规则若不同，最终以学校教务系统为准。

## 6. 安排任务与专注时间

1. 进入 **学习计划**，把任务填进周一到周日的看板；暂未确定日期的放入 **收件箱**。
2. 任务名称末尾可以写预计时间，例如 `复习操作系统 30分钟`。
3. 为作业设置截止日期，并关联对应课程、学科、证书或升学方向。
4. 拖动任务可以换日期，完成后勾选。
5. 点击宿舍台灯、底部 **专注** 或学科中的 **学这科** 开始计时，选择时长或自定义。

切换功能页不会中断计时，刷新后也能接着计时。学习计划中可查看本周专注时长和时间分配。

## 7. 记录证书、升学就业与生活

**证书与驾照**：添加证书，填写状态、报名截止、考试日期、目标分和成绩；驾照可分别记录科目一至科目四的状态、约考日期和结果。及时更新日期，宿舍倒计时才会反映实际安排。

**升学就业**：可同时选择考研、保研、留学、就业、考公考编或自定义方向。在方向内完善时间节点、准备清单和笔记，将重要日期上墙显示。自动生成的时间节点只是参考，请按官方公告修改。

**宿舍生活**：睡前进入 **熄灯** 并记录入睡，起床后点 **我起床了**；运动后记录项目、时长和校园跑；饭后记录餐次与花费，喝水可直接点击桌上的马克杯。各模块可设置自己的目标和预算。

## 8. 使用 AI 助手（可选）

### 不配置 API：复制提示词

1. 进入 **AI 助手**，选择复习计划、成绩分析、简历优化等模板。
2. 填写模板中的信息，点击 **复制提示词** 或 **生成（复制提示词）**。
3. 查看生成的提示词，确认其中包含的个人资料。
4. 复制到自己使用的 AI 网页或 App 中发送。

生成和复制提示词本身不需要配置 AI 接口；在其他 AI 服务中粘贴并发送后，内容会由该服务处理。

### 配置 API：在工作台内直接生成

1. 打开 **设置 → AI 接口**，选择服务商。
2. 填写 **API Key、接口地址（Base URL）、模型名称**。接口地址与模型名称请以服务商控制台提供的内容为准，预设值可以修改。
3. 根据需要保留 **发送前隐去姓名和学校**。
4. 点击 **测试连接**。成功后返回 AI 助手，使用模板的 **开始生成**，或在输入框提问。
5. 自由提问时，按需选择 **我的情况、历学期成绩、本周课表**，再发送。

测试连接也会向已配置的服务发出请求，可能按该服务的规则计费。模板会按场景组织相关资料，自由提问会附上所选背景；后续追问也会包含相关对话内容。

“隐去姓名和学校”只替换设置中的姓名和学校，不等于移除成绩、专业、经历或正文中的其他个人信息。API Key 保存在本机浏览器中，调用时会通过请求头发送给配置的服务；使用中转时，中转也会接收并转发请求。请只填写自己信任的接口。

### 遇到跨域限制：使用本地中转

随包的 `ai-proxy.js` 用于把浏览器请求转发到 HTTPS AI 接口，无需安装 npm 依赖。

1. 安装 Node.js 18 或更新版本。
2. 在包含 `ai-proxy.js` 的项目文件夹打开终端，运行：

   ```bash
   node ai-proxy.js
   ```

3. 保持终端运行，在 **设置 → AI 接口** 中，为原 Base URL 加上 `http://127.0.0.1:8787/` 前缀。例如原地址为：

   ```text
   https://api.deepseek.com
   ```

   改为：

   ```text
   http://127.0.0.1:8787/https://api.deepseek.com
   ```

4. 保留服务商、API Key 和模型配置，再点 **测试连接**。
5. 不使用时，在终端按 **Ctrl + C** 停止中转。

中转只监听本机 `127.0.0.1:8787`，代码不保存请求内容；请求仍会发往目标 AI 服务。这个脚本只支持 HTTPS 目标，不用于转发 `http://localhost:11434` 等 HTTP 本地接口。使用 Ollama 时，应直接配置其本地地址并按本机环境设置访问权限。

## 9. 备份、恢复与换电脑

日常数据主要保存在浏览器 localStorage，学科附件保存在 IndexedDB。软件没有账号同步或自动云备份；换浏览器、换浏览器用户配置、清理站点数据或移动文件，都可能导致无法访问原来的数据。

### 导出备份

1. 打开 **设置 → 数据与备份**，检查 **存储状态**。
2. 点击 **导出备份**，保存下载的 `.json` 文件。
3. 留意完成提示中是否说明附件过大、未放入备份。
4. 在更新软件、移动文件、清理浏览器或更换电脑前，再做一次备份。

学科附件总量不超过 **30 MiB**（界面标为 30MB）时，程序尝试把可读取的附件一并打包；**超过上限时，所有附件内容都会跳过，并非只跳过超出的部分**。此时请在各学科中单独下载文件，换电脑后重新添加。

**备份会包含个人记录、AI 对话和已配置的 API Key，而且没有加密。请私下妥善保存，不要上传 GitHub 或公开分享。** 仅分享软件时，分享仓库或程序文件即可，不要附上自己的备份。

### 从备份恢复

1. 如当前已有数据，先导出一份备份。
2. 在目标电脑或浏览器打开 `index.html`。
3. 进入 **设置 → 数据与备份 → 从备份恢复**，选择 `.json` 文件。
4. 阅读确认框，确认后点击 **恢复**。恢复会覆盖当前应用数据，不会将两份记录自动合并。
5. 检查课表、成绩、笔记与附件是否完整；对于未包含在备份中的附件，重新添加单独保存的文件。

**载入示例同学** 和 **清空全部数据** 也会覆盖或清除当前记录，使用前先备份。

## 10. 常见问题

| 问题 | 处理方法 |
|---|---|
| 双击后显示源码或打开了编辑器 | 用“打开方式”选择 Chrome 或 Edge |
| 第几周不对或课程时间不对 | 检查设置中的本学期、开学日期和作息时间 |
| 课表导入后时间重复 | 同名课程的时间段会追加，检查并删除重复时间段，不要重复导入整表 |
| GPA 与教务系统不一致 | 核对算法、学分、课程类型和选修计入规则，以教务系统为准 |
| 换了浏览器后记录消失 | 不同浏览器的数据不共享，回原浏览器导出备份，再到新浏览器恢复 |
| 附件名还在，但打不开 | 检查是否从未包含附件的备份恢复，找到原文件后重新添加 |
| AI 提示模型不存在或没有权限 | 核对接口地址、模型名称、API Key 和服务商账号权限 |
| AI 提示连不上 | 核对网络与配置；若为跨域限制，尝试本地中转或复制提示词方式 |
| 手机排版不合适 | v1.1 面向电脑端，建议在电脑浏览器中使用 |
